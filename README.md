# WoodVideo Broadcast downloads

Releases of **WoodVideo Broadcast** by Whoastra Labs LLC: turns any window or monitor on a Windows PC into a live video stream for the survey network — an RTSP stream for VisualSoft, VLC or any DVR, a UDP MPEG-TS stream, and a browser viewer — and keeps it running for weeks, restarting itself and re-finding the source window when the program behind it is reopened.

This repository holds the program downloads only; the source code is not public.

- Website: https://whoastra-labs-site.vercel.app/woodsolutions/woodvideobroadcast
- All downloads: https://github.com/WHoastra/WoodVideoBroadcast-Releases/releases — `WoodVideoBroadcast-portable.zip` is a portable folder: unzip it anywhere and run `WoodVideo Broadcast.exe`; nothing to install.

Windows SmartScreen may show a notice on a new publisher's program: choose *More info*, then *Run anyway*. FFmpeg (bundled) is free software under the LGPL/GPL and is not a Whoastra Labs product.
